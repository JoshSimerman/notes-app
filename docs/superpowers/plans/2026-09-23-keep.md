# Notes Implementation Plan

> Execution: implement inline using the executing-plans workflow; test risky contracts first, then verify the complete application.

**Goal:** A mobile-friendly private notes application running on Cloudflare at an owner-configured domain.

**Architecture:** React SPA and a same-origin Hono Worker, with D1 for notes, preferences, sessions, and persistent login cooldowns. Use Workers static assets and Turnstile.

**Tech Stack:** TypeScript, React 19, Vite 8, Cloudflare Workers/D1, Hono, Zod, Lucide, Vitest, Playwright.

**Spec:** ../specs/2026-09-23-keep-design.md

## Global Constraints

- No user accounts or external application hosting.
- APP_PASSWORD is a server secret; production requires Turnstile and HTTPS.
- One-year revocable secure cookie; trash retention is 90 days.
- No sidebar or save/edit mode. Persist completed-item visibility per note.
- Plain text only: no HTML rendering of note content.

## Review Focus

- Lost save responses must retry without duplicate notes or false conflicts.
- Two devices editing one note must preserve both sets of edits.
- Refresh, failed network requests, and session expiry must retain pending drafts.
- Long titles, many checklist items, and narrow mobile widths must not overflow.
- Password rotation, missing production config, hostile origins, and expired trash must fail safely.
